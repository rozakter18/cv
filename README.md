# CV (auto-built)

Every push to `main` compiles `main.tex` and publishes the PDF at a fixed link:

**https://github.com/rozakter18/cv/releases/download/cv-latest/Roza_Akter_CV.pdf**

My portfolio's "Download CV" button points to this link, so it always serves the latest version.

## Update the CV
Edit the `.tex` file(s) and push (or upload them on GitHub). The PDF rebuilds in about 1–2 minutes. Check progress in the **Actions** tab.
